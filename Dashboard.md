# 🚀 Willkommen im Task & Time Tracker

Dieses Dashboard dient als Ihre zentrale Steuerzentrale für Aufgabenverwaltung, Mehrtages-Planung und Zeiterfassung in Obsidian.

---

```task-tracker
view: cockpit
```

---

## 📌 Schnellstart & Funktionen

- **🏠 Cockpit**: 
  - Nutzen Sie die Buttons oben für `+ Neuer Task` oder `+ Zeit buchen`.
  - Bei aktiven Aufgaben können Sie mit `[+0.5h]` oder `[+1.0h]` sofort Arbeitszeit auf den heutigen Tag buchen.
  - Mit `[▶ Timer]` starten Sie eine Live-Stoppuhr, die in der Statusleiste mitläuft.
- **📅 Kalender**:
  - Wechseln Sie im Cockpit oder über das Uhren-Symbol in der linken Seitenleiste auf **Kalender**.
  - Der Kalender zeigt Tagesstundensummen, gebuchte Aufgaben-Chips und Zeitspannen über mehrere Tage.
  - Klicken Sie auf einen beliebigen Tag im Kalender, um direkt eine Buchung oder Aufgabe anzulegen.
- **📊 Historie & Auswertungen**:
  - Gruppieren Sie gebuchte Stunden nach Tag, Aufgabe, Tags oder Kostenstellen.
  - Exportieren oder kopieren Sie Berichte direkt als Markdown- oder CSV-Tabelle.
- **📝 Eigene Notizen einbinden**:
  - Sie können den Tracker in jede beliebige Notiz einbinden:
    - ```` ```task-tracker ``` ```` (Cockpit)
    - ```` ```task-tracker\nview: calendar\n``` ```` (Kalender)
    - ```` ```task-tracker\nview: history\n``` ```` (Historie)
